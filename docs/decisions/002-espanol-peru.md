# ADR-002: Español del Perú como idioma principal

## Estado y fecha

Aceptada el 15/11/2026 por indicación de Keneth. Cristopher y Jordan trabajan principalmente en español.

## Decisión

Usar español latinoamericano adaptado al Perú en documentación vigente, tareas, hitos, tablero,
formularios, mensajes visibles y títulos/descripciones de PR. Usar vocabulario claro: archivo,
carpeta, equipo, datos faltantes, responsable y conjunto de datos. Evitar traducciones literales
confusas y explicar términos técnicos: PR es una solicitud de cambios y CI es integración continua.

Mantener identificadores, rutas, comandos, claves JSON/YAML, estados internos, nombres de API y
marcas de herramientas para conservar compatibilidad. Los nombres técnicos del código pueden seguir
en inglés; las ayudas del programa son en español. Los prefijos de Conventional Commits se mantienen.

La indicación de escribir documentación en inglés del documento inicial queda reemplazada.
`docs/initial-plan.md` también se traduce; el historial de Git conserva el texto original.
Las contribuciones externas seguirán el idioma que exija TimeNet.

## Consecuencias

El equipo puede planificar y revisar en su idioma habitual sin cambiar contratos técnicos.
La traducción debe conservar criterios de aceptación, dependencias, responsables, evidencia,
permisos de publicación y exigencias de calidad. No se cambian nombres de comandos ni identificadores de estados de GitHub o de los controles de
main. Los nombres visibles del tablero sí se traducen conservando los mismos identificadores.
